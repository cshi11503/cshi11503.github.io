# Casey Shi | Robotics research portfolio

Local React + Vite portfolio. Use Node.js 20.19+ or 22.12+.

```sh
npm ci
npm run dev
```

Open the Local URL Vite prints. To check the production build, run `npm run build` and then `npm run preview`. The deployable static files are generated in `dist/`.

Edit the content in `src.jsx` and the design in `style.css`. The hiking illustration and research images live in `public/`.
